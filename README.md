# QR Solar – Website-Entwurf

Statischer Mehrseiter (18 Seiten), Apple-/Awwwards-Stil. Design-Kontrakt in `DESIGN.md`, offene Punkte in `LAUNCH-CHECKLISTE.md`.

- Seiten bauen: `python3 _build.py` (erzeugt alle HTML-Dateien + sitemap.xml aus dem Generator)
- Lokal ansehen: `python3 -m http.server 8766` im Projektordner → http://127.0.0.1:8766
- Veröffentlichen: `git add -A && git commit -m "…" && git push` → https://nilsc2308.github.io/qr-solar-website/
